

# Task Tracker

O **Task Tracker** é uma ferramenta de linha de comando (CLI) desenvolvida em Python que visa descomplicar a maneira de lidar com tarefas e reduzir ao máximo as distrações causadas por aplicativos de organização convencionais. Com uma interface simples e direta, você pode adicionar, listar e remover tarefas facilmente, mantendo o foco no que realmente importa.

## Funcionalidades

- **Adicionar Tarefas:** Insira novas tarefas com um comando simples.
- **Listar Tarefas:** Visualize rapidamente todas as suas tarefas pendentes.
- **Remover Tarefas:** Elimine tarefas indesejadas com facilidade.

## Como Usar

1. Clone o repositório ou baixe o código.
2. Certifique-se de ter o Python instalado em sua máquina.
3. Execute o script `main.py`.
4. Utilize os comandos disponíveis:
   - `add [tarefa]` para adicionar uma nova tarefa.
   - `list` para listar todas as tarefas.
   - `remove [número]` para remover uma tarefa específica.
   - `quit` para sair do aplicativo.

## Exemplo de Uso

```bash
-->>> add Fazer compras
Added task: Fazer compras

-->>> list
1: Fazer compras (Added on: 15:30)

-->>> remove 1
Removed task: Fazer compras
```
